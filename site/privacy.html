隐私说明

这份说明描述浮笺当前版本如何处理数据。

保存在本机

任务、随记、设置和窗口位置默认保存在本机用户目录。未登录时，它们不会上传到云端。

登录与同步

登录需要邮箱验证码。登录后，任务和随记会同步到浮笺使用的 Supabase 数据库，以便同一账号在不同设备上看到同一份内容。数据按账号隔离，不会公开展示。

云端数据目前不是端到端加密。请不要把密码、密钥或其他高度敏感信息放进任务或随记。

AI 关键词

只有在你主动点击「生成关键词」时，当前随记的标题和正文才会发送到 DeepSeek API。API Key 使用系统安全存储加密保存在本机，不会上传到 Supabase，也不会显示在设置页明文里。

邮件

邮箱只用于发送登录验证码。验证码通过 Resend 和浮笺的邮件域名发送，不会用于营销邮件。

联系

如需删除账号或数据，请通过 GitHub Issues 联系维护者。请勿在公开 Issue 中粘贴验证码、API Key 或私人任务内容。
