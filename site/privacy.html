隐私说明 Privacy Notice

这份说明描述浮笺当前版本如何处理数据。 This notice describes how the current version of Fujian handles data.

保存在本机 Stored on this device

任务、随记、设置和窗口位置默认保存在本机用户目录。未登录时，它们不会上传到云端。 Tasks, notes, settings, and window position are stored in your local user folder by default. When signed out, they are not uploaded.

登录与同步 Sign-in and sync

登录需要邮箱验证码。登录后，任务和随记会同步到浮笺使用的 Supabase 数据库，以便同一账号在不同设备上看到同一份内容。数据按账号隔离，不会公开展示。 Sign-in requires an email code. After signing in, tasks and notes sync to the Supabase database used by Fujian so the same account can see the same content across devices. Data is isolated by account and is not publicly displayed.

云端数据目前不是端到端加密。请不要把密码、密钥或其他高度敏感信息放进任务或随记。 Cloud data is not end-to-end encrypted. Do not put passwords, keys, or other highly sensitive information in tasks or notes.

AI 关键词 AI keywords

只有在你主动点击「生成关键词」时，当前随记的标题和正文才会发送到 DeepSeek API。API Key 使用系统安全存储加密保存在本机，不会上传到 Supabase，也不会显示在设置页明文里。 Only when you explicitly choose “Generate keywords” is the title and content of that note sent to the DeepSeek API. The API key is encrypted with the system secure storage on this device; it is not uploaded to Supabase or shown in plain text in Settings.

邮件 Email

邮箱只用于发送登录验证码。验证码通过 Resend 和浮笺的邮件域名发送，不会用于营销邮件。 Email is used only to send sign-in codes. Codes are sent through Resend and Fujian’s email domain, and are never used for marketing.

联系 Contact

如需删除账号或数据，请通过 GitHub Issues 联系维护者。请勿在公开 Issue 中粘贴验证码、API Key 或私人任务内容。 To delete your account or data, contact the maintainer through GitHub Issues. Do not post verification codes, API keys, or private task content in public issues.
